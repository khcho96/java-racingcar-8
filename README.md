# java-racingcar-precourse

## 기능 구현 목록
> 기능 작동 순서대로 작성

1. 경주할 자동차 이름 입력 및 검증
    - 예외 사항
        - 잘못된 형식인 경우 -> Validator
            - 잘못된 형식입니다.
2. 자동차 정보 저장 및 이름 검증
    - 예외 사항
        - 이름이 5자 초과인 경우 -> Car
            - 이름은 5자 이하만 가능합니다.
        - 이름이 중복인 경우 -> Cars
            - 이름이 중복입니다.
3. 시도 횟수 입력 및 검증
    - 예외 사항
        - 숫자가 아닌 경우 -> Validator
            - 잘못된 형식입니다.
4. 시도 횟수 저장
   - 예외 사항
       - 1 이상의 숫자가 아닌 경우 -> Round
           - 1 이상의 숫자를 입력해주세요.
5. 경주 진행
    1. 자동차별 무작위 값 생성
    2. 값에 따른 행동
        - 4 이상: 전진
        - 4 미만: 정지
    3. 결과 저장
    4. 결과 출력
6. 경주가 종료되면 최종 우승자 출력
